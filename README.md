# SwayShell

A simple bootstrap installer for my personal SwayFX desktop setup on Arch Linux.

## Features

- SwayFX compositor with visual effects
- Waybar with a custom translucent theme
- Alacritty terminal
- Fuzzel application launcher
- Swaylock with a custom dark blue theme
- Snypr screenshot and annotation tool
- Custom misty forest wallpaper
- Media, audio and brightness keybindings

## Requirements

- Arch Linux
- `yay` or `paru` (AUR helper)
- Internet connection
